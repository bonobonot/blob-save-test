이미지 저장 방식 실험

LINE 안에서 이미지를 사진 앨범에 저장할 수 있는 방식을 찾는 실험입니다.

  1. 이 페이지 주소를 LINE 「나와의 채팅」에 보내고, 링크를 탭해 LINE 안에서 엽니다.
  2. 항목마다 버튼을 누르고, 사진 앨범에 실제로 저장됐는지 확인해 O / X 를 고릅니다. 눌러도 아무 일이 없으면 X 입니다.
  3. 맨 아래 「결과 복사」로 환경과 결과를 복사해 공유합니다.

환경:

1. https 주소의 이미지

기본값은 이 페이지와 같은 서버의 sample.png 입니다. 다른 주소를 넣으면 그 이미지로 시험합니다. URL 이 이 페이지와 다른 origin 이면 브라우저가 download 속성을 무시할 수 있습니다.

2. 페이지 안에서 만든 이미지 (blob)

서버에서 헤더를 실어 fetch 로 받은 이미지는 페이지 안에서 blob 이 됩니다. 여기서는 같은 방식으로 sample.png 를 받아 blob 을 만듭니다. 받기에 실패하면 페이지가 직접 그린 PNG 를 씁니다.
